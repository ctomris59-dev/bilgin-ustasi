# Game Assets

Bu klasördeki dosyalar Bilgin Ustası'nın görsel oyun varlıklarıdır.

Yeni üretilecek varlıklar için önerilen standart:
- şeffaf arka plan
- kare ürün görselleri: 512x512 veya 1024x1024
- avatar renderı: yaklaşık 4:5 oran
- aynı ışık yönü ve aynı çizim stili
- dosya isimlerinde küçük harf ve tire kullanımı

Asset bağlantıları: `src/data/gameAssets.js`
